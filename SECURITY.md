# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
(<https://github.com/airalab/altruist-firmware/security/advisories/new>).

Include the firmware version (shown on the device status page), the hardware
model, and steps to reproduce. We will acknowledge the report and keep you
updated while it is being fixed.

## Supported versions

Only the latest Stable release on the `esp32` branch receives security fixes.
